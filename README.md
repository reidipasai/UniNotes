# UniNotes

Η εφαρμογή UniNotes δίνει τη δυνατότητα στους φοιτητές του ΕΜΠ να αναρτούν και να αποθηκεύουν σημειώσεις καθώς και ηχητικές καταγραφές διαλέξεων/σεμιναρίων.

Πιο συγκεκριμένα:

* Οι φοιτητές μπορούν να βγάζουν φωτογραφία τις σημειώσεις τους μέσω της εφαρμογής και να τις ανεβάζουν στο forum κάθε μαθήματος, όπου είναι διαθέσιμες για κατέβασμα σε μορφή PDF.
* Υπάρχει η δυνατότητα ηχογράφησης διαλέξεων μέσω της εφαρμογής, με ανάρτηση των ηχογραφήσεων στο forum, ώστε να μπορούν οι υπόλοιποι φοιτητές να τις ακούσουν.
* Η εφαρμογή δεν περιλαμβάνει τελικά δυνατότητα δημιουργίας περίληψης σε κείμενο από ηχογραφήσεις.
* Κάθε μάθημα διαθέτει το δικό του forum για σημειώσεις και ηχογραφήσεις, καθώς και ένα κανάλι συνομιλίας (chat) για συζήτηση αποριών και ανταλλαγή ιδεών.
* Κάθε σημείωση μπορεί να λάβει Likes, με αποτέλεσμα οι φοιτητές να μπορούν να ξεχωρίζουν εύκολα τις πιο ποιοτικές.
* Υπάρχει επίσης ένα leaderboard που εμφανίζει τους φοιτητές με τις πιο ποιοτικές συνεισφορές (με βάση τον αριθμό likes σε σημειώσεις και ηχογραφήσεις).


## Άξονας 1 

* Gamification: Βαθμός εμπιστοσύνης φοιτητή ανάλογα με τη συνεισφορά του (leaderboard).
* Συνεργατικός, πληθοριστικός και κοινωνικός υπολογισμός (Collaborative, Crowdsourcing & Social Computing).


## Άξονας 2

* Όραση (Camera): Χρήση κάμερας για καταγραφή και ανέβασμα σημειώσεων.
* Ηχητικό υποσύστημα (Audio): Χρήση μικροφώνου για ηχογράφηση και ηχείων για ακρόαση διαλέξεων.
* Υποσύστημα Αφής (Haptics): Χρήση δονήσεων για ειδοποιήσεις (όταν λαμβάνεις μήνυμα από συμφοιτητή).
* Νευρωνικά Δίκτυα: Δεν υλοποιήθηκαν τελικά στη τρήτη φάση.


## Άξονας 3

* Μηνύματα και Ειδοποιήσεις: Ενσωμάτωση chat για αποστολή μηνυμάτων και ανταλλαγή ιδεών.

## Installation

Αυτή την στιγμή η εφαρμογή μπορεί να λειτουργήσει μόνο σε emulator, αυτό διότι
δεν είχαμε VM ώστε να κάνουμε host το database μας, κάτι που θα κάνουμε στο
μέλλον αν χρειαστεί. Θα χρειαστεί να έχετε mongodb installed(συνιστούμε mongodb
compass).

Για να αρχίσετε το backend, θα χρειαστεί να κάνετε τα παρακάτω στο database/
```bash
pip3 install -r requirements.txt
fastapi run app.py --host localhost
```

Έπειτα, για να τρέξετε τον emulator και την εφαρμογή, θα κάνετε:
```bash
flutter emulators --launch Medium_Phone_API_36.0
flutter run
```
